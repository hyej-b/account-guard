# 계정 지킴이

퇴사자·계약 종료 계정을 먼저 찾아 주는 전산팀 점검 도구
전산팀 변혜정 · 장금그룹 업무 도구 포탈 — 사내 AI 교육 실전 과제

국내·해외 직원과 해외 대리점·거래처의 시스템 계정을 인사 명단·거래처 계약 목록과 자동으로 대조해, 퇴사자 계정·계약 종료 거래처 계정·미접속·권한 과다 계정을 고정 규칙으로 찾아냅니다.

- 현황: 국가·지사·대리점별 지도, 사유별 건수, 자동 발견 사항
- 권한 비교: 직무별 표준 권한 대비 실제 권한
- 조치 목록: 판정 사유·권장 조치·처리 상태 기록, CSV 내보내기
- 안내문: 받는 곳별 한국어·영어 초안
- 데이터·규칙: CSV 올리기, 형식 점검, 기준값 변경

`index.html` 파일 하나로 동작합니다(외부 라이브러리 없음). 직원·거래처·계정은 모두 가상 데이터입니다.
